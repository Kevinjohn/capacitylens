OWASP ASVS 5.0.0 complete control ledger ​

Original assessment date: 2026-08-18. Authentication and related controls amended: 2026-10-26, after the Account Kit cutover. Every Level 1–3 requirement is assessed. Password-only deployments do not meet the Level 2 multi-factor requirement. Baseline: OWASP Application Security Verification Standard 5.0.0 (May 2025), 345 requirements.

This ledger is an evidence-based source/configuration review, not an OWASP certification. It uses:

  • Pass — implemented or deliberately avoided, with repository evidence and tests where practical;
  • Partial — meaningful controls exist, but a clause, deployment proof or higher-assurance aspect is incomplete;
  • Gap — applicable requirement is not implemented;
  • N/A — the governed technology/function does not exist in CapacityLens.

An inherited library/framework control is only marked Pass where the application constrains its use and the behavior is covered by configuration/tests or the maintained library contract. External TLS, disks, collectors, secret stores and external authentication policy cannot become Pass merely because an environment acknowledgement is set; those stay Partial where deployment evidence is required. Requirement descriptions are not reproduced here; use the official ASVS 5.0.0 release alongside these IDs.

Original 2026-08-18 totals: 200 Pass, 48 Partial, 7 Gap and 90 N/A = 345. Following the 2026-10-09 local MFA removal, the 2026-10-21 retirement of the automated cryptographic path check, and this 2026-10-26 authentication amendment, the current rows total 152 Pass, 58 Partial, 16 Gap and 119 N/A = 345. These are not a score or certification percentage.

Interpretation ​

CapacityLens supports password sign-in only and has no local multi-factor authentication or breached-password screening. It therefore does not meet V6.3.3 L2. A Gap in a Level 3-only requirement documents a higher-assurance boundary rather than an L2 failure. Partial/Gap controls remain real limitations, including password-hash parameters, authentication event logging, URL bearer links and deployment public-TLS/secret/log/storage evidence.
