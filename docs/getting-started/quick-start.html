Get started quickly ​

Use this page to reach the right starting point in under a minute. You do not need to read the documentation from beginning to end.

Steps ​

  1. Choose what you want to do.

    • To explore CapacityLens without keeping any data, try the demo.
    • To put CapacityLens on a server, choose an installation route.
    • If somebody else has already installed it, ask an Owner or Admin for an invitation link, then follow Invite your team.

  2. Finish the first company setup. The person responsible for the new installation should follow Set up your company as Owner. It connects the technical installation to the first useful schedule and explains when to involve an Admin.

  3. Learn only the screen you need. Start with The schedule, then use People and placeholders, Projects and allocations, or Time off when that job comes up.

  4. Return to the specialist sections when needed. Admin and settings covers company options, while Self-hosting covers backups, upgrades, monitoring and incidents.

What's next ​

Try the demo for the fastest look, or choose how to install CapacityLens to keep your own data.
