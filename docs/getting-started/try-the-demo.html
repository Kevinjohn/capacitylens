Try the demo ​

You run a sample agency's schedule on your own machine in about two minutes. Nothing is saved: schedule changes reset when you refresh, and there is no real sign-in. Display preferences may stay in your browser. To keep real data, install CapacityLens instead.

You need Node.js 24 or newer (check with node --version) and pnpm, which corepack in Node provides.

Run it ​

  1. Clone the repository, check out a release and install dependencies:

    bash
    git clone https://github.com/Kevinjohn/capacitylens.git
cd capacitylens
git checkout vX.Y.Z
corepack enable && pnpm install

    Replace vX.Y.Z with the newest tag on the releases page. Otherwise you run unreleased changes on main.

  2. Start the demo:

    bash
    pnpm run dev:demo

  3. Open http://127.0.0.1:5173 in your browser.

No setup token, .env file or database is needed.

What you'll see ​

Choose the sample account on the Choose an account screen; there is no password. The schedule opens with people, clients, projects and bookings already in place.

What to click first ​

  1. Open the filters. Select Show filters at the far right of the Schedule toolbar.

  2. Filter to a project. Open All projects and choose one. Clear Filters turns red while the view is narrowed.

  3. See who is free. Select Show unallocated. People without work on that project return as dimmed rows.

  4. Move some work. Select Clear Filters, then drag a booking to another week and watch the Utilisation percentage update.

  5. Zoom out. Change Weeks visible from two weeks to four or six.
