Install and run CapacityLens ​

You put CapacityLens on a server and hand it to the company's Owner. It is one Node process and one SQLite file. There is no database server to run and nothing to build. On a host that already runs Node 24 and has a hostname pointing at it, the install takes about ten minutes.

  1. Install it. Download the release archive, pick a folder for the data, generate the settings with one command, start the server, and open the address. Those are the five install steps, the same on a managed host such as Forge as on your own Linux server.

  2. Put HTTPS in front. A managed host issues the certificate for you. On your own server, Caddy does it in four lines. Finish this before anyone enters a password. TLS and networking

  3. Turn on backups. Set CAPACITYLENS_BACKUP_DIR and CapacityLens takes a safe snapshot of the database every hour. Keep a copy of the environment file somewhere other than the server. Backups and restore

  4. Hand over. Check https://your-address/api/health returns {"ok":true. Send the Owner the address and Set up your company, and send the setup token separately and privately. This is the screen they will see. Verify and hand over

What you're taking on ​

Self-hosting means you, or someone you name, own the service after handover. That means keeping backups tested, watching health and disk space, and installing new releases. Support is community help on a best-effort basis, with no guaranteed response time. Get help explains where to ask.

Other ways to install ​

  • Deploy on a managed VPS platform such as Forge, Ploi or RunCloud, working in the platform's own screens.
  • Install without Docker on a Linux host with systemd.
  • Install with Docker if your host already runs Docker.
  • Try the demo first if you only want to look around.
