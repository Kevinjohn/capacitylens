Install and run CapacityLens ​

CapacityLens runs as one Node process and stores company data in SQLite. These five steps are for whoever manages your hosting. That person also handles backups, upgrades and service health. The expected installation is the native release archive with an HTTPS proxy on the same machine.

  1. Download and unpack the archive for your host.
  2. Choose a data folder outside the release directory.
  3. Configure the private environment, secrets, public address and backups.
  4. Start the service after its database upgrade, with HTTPS at the same-machine proxy.
  5. Open the address and complete sign-in and company naming in the browser.

Install without Docker gives the exact Linux commands; Deploy on a managed host explains the process-manager requirements. Existing Docker support remains optional. A proxy in a separate container or on another machine is not yet supported.

Before handover, read Configuration, TLS and networking, Backups and restore, Upgrades and Monitoring.

Support ​

The operator owns backups, upgrades, service health, disk capacity and changes to sign-in settings. For an incident, see When something goes wrong. For community help, see Get help; do not include credentials, bearer links or private customer data in a public report.

Other ways to try CapacityLens ​

Try the demo for temporary sample data. The demo is not an installation route and must not hold production scheduling data.
