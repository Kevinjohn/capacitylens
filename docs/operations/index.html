Operate a self-hosted installation ​

This guide is for the technical person responsible for keeping an existing CapacityLens service healthy. It assumes installation and first-Owner handover are complete.

Choose the task you need ​

  • Back up or restore data.
  • Upgrade to another release.
  • Monitor health and storage.
  • Change service configuration.
  • Set up company login or move an existing team to it.
  • Recover a blocked ownership transfer.
  • Diagnose an incident.

You do not need to read these runbooks in order. Open the one that matches the current task, and return here when the responsibility changes.

Routine minimum ​

Keep tested backups, monitor health and disk space, apply supported upgrades, and make configuration changes through a reviewed restart. Coordinate sign-in and member-facing changes with an Owner or Admin.

What's next ​

Start with Backups and restore if operational ownership has just been handed to you.
