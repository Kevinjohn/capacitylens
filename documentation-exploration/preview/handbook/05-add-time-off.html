Time off

For: Editor, Admin, Owner, Viewer

Add time off ​

Record known absences before booking work. An Editor, Admin or Owner can add time off; a Viewer asks the person who plans the schedule to record it.

  1. Open Time off and select Add time off.
  2. Choose the Resource, Start, End and Type. Start and end include both dates.
  3. Leave Repeat as Doesn’t repeat for one absence, or choose a pattern and cutoff date for repeated absences. Add a short Note if useful, then select Save.

The absence appears on the person's Schedule row as a hatched block and removes capacity for those dates. Notes are visible only to Owners and Admins; other roles see the dates without the note.

If work is already booked ​

Time off does not delete or move bookings. An overlapping booking remains visible so the planner can decide whether to change it. Review the person's row and resolve any red conflict with Resolve overbooking.

A Viewer cannot submit a personal holiday request inside CapacityLens. Ask an Editor, Admin or Owner to add the dates; arrange the request outside the product. Company closures are a separate whole-company action managed by an Editor or above on Time off.

Continue with Find capacity before choosing dates for new work.
