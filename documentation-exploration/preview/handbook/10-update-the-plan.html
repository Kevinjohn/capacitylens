Schedule

For: Editor, Admin, Owner

Update the plan ​

Review Schedule when dates, staffing or work change. Check the visible weeks, utilisation and red daily bands, then update bookings and known time off. A changed working pattern or absence can create an overlap without moving existing bookings.

A bar can change before the server confirms the save. Check for a save warning rather than relying on its position alone. If a save is refused because the schedule changed in another session, close and reopen the form, then re-apply your edit to the latest data. Do not keep submitting values from the old form.

If saving is interrupted, the page may say Changes aren’t being saved right now — we’ll keep retrying. Keep the page open and check that the warning clears. If CapacityLens cannot confirm every saved change, it reloads the latest server copy. Review recent changes against that copy, then re-apply anything missing. Scheduling data is not stored locally for later submission, so the browser is not an offline plan. If the page says the schedule could not be loaded, reload to try again.

Select Undo in the Schedule toolbar to reverse a recent supported change, or Redo to restore it. The keyboard shortcuts are Ctrl+Z to undo and Ctrl+Shift+Z to redo (on macOS, ⌘Z and ⌘⇧Z). Undo is available only while the recent change remains in local history. A reload or a server refresh that includes someone else’s changes can clear that history. A repeated booking series can be undone as one saved change, but later edits to its individual bookings are separate.

After an adjustment, recheck the affected dates and person. Resolve overbooking covers reassignment and capacity checks; Check your week shows the Viewer path.
