Resources

For: Editor, Admin, Owner

Add people ​

Add a resource for each person whose capacity you want to plan. Editors, Admins and Owners can edit resources; Viewers cannot. A schedule person does not need a sign-in.

  1. Open Resources and select Add resource.
  2. Enter Name. Add Role to describe their work, choose Engagement, and choose Discipline if your company uses disciplines. The resource Role is a job description, not their access permission.
  3. Set Working days to the person's normal pattern. Choose full day, half day or not working for each day. Set Start date or End date when their availability is limited; each date is inclusive.
  4. Select Save. The person is available as a row on Schedule.

The person's capacity uses days that are working both for the company and for that person. Correct the pattern before planning so utilisation reflects their actual availability. A changed pattern or availability does not move or delete existing bookings; review any resulting conflicts.

Link a teammate's sign-in ​

Membership and schedule resources are separate. Only an Owner or Admin can manage the member link. First invite the teammate, then open Team & access, select the link icon on their member row, and choose the resource. The link saves immediately. Linking does not change the member's access role or create a schedule row.

If the teammate only needs to appear on the plan, do not invite them. If they need to sign in and read or edit the plan, invite them in Get access, then link them here. Continue with Add work to prepare what the team will book.
