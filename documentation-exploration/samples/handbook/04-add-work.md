# Add work

Editors, Admins and Owners can prepare work. For a client project, create the client first, then the project and a project-specific activity.

1. Open **Clients**, select **Add client**, enter a name and select **Save**.
2. Open **Projects**, select **Add project**, enter a name, choose that **Client** and select **Save**.
3. Open **Activities**, select **Add activity**, enter a name, set **Kind** to **Project-specific**, choose the **Project**, and select **Save**.

For a concrete example, use client **Wayne Enterprises**, project **Website refresh**, and activity **Design**. They will then be available in the booking form.

**All projects** activities are reusable across projects. **Internal** activities are for internal work and are booked under the Internal project. Those two kinds do not need a client or project to be created. A project-specific activity belongs to one project.

Keep activities broad enough to support week-by-week capacity planning. CapacityLens plans work by date range and amount; it is not a task tracker or timesheet. Once the person's row, project and activity are ready, see [Book work](07-book-work.md). Record known absences before booking work with [Add time off](05-add-time-off.md).
