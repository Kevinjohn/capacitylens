# Plan next week

Start with **Schedule**. A person with a schedule row and work ready to book is enough to make a useful plan; invite the people who need to sign in, then add resources, work and bookings as needed. This route assumes CapacityLens is installed and the first Owner has created the company.

You can enter at the task you need. There is no need for everyone to read all ten pages.

1. **Give teammates access.** An Owner or Admin invites Editors who will plan and Viewers who will read the plan. Accepting an invitation creates a sign-in membership, not a schedule row; any required admission checks still apply. See [Get access](02-get-access.md).
2. **Add schedule people.** An Editor or above creates each person and their working pattern. An Owner or Admin separately links a member to a resource when they need both sign-in and a schedule row. See [Add people](03-add-people.md).
3. **Prepare the work and availability.** Editors and above add clients, projects and activities, then record known time off before booking. See [Add work](04-add-work.md) and [Add time off](05-add-time-off.md).
4. **Find room and book.** Check Schedule's visible window and warning, then book work or resolve conflicts. See [Find capacity](06-find-capacity.md), [Book work](07-book-work.md) and [Resolve overbooking](08-resolve-overbooking.md).
5. **Let a Viewer check the plan.** Viewers can read Schedule and their work list but cannot change the plan. See [Check your week](09-check-your-week.md).

The Owner may hand daily planning to an Admin. Editors can prepare and change scheduling data; only Owners and Admins manage invitations and membership. If a page or action is unavailable because email, server access or membership is missing, ask the Owner or installer. For an access issue, start at [Get access](02-get-access.md).
