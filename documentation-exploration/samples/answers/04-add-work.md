# What work can I book?

An **Editor**, **Admin** or **Owner** can prepare the work choices used by the booking form. Create a client in **Clients** with **Add client**. In **Projects**, choose **Add project**, enter its name and select the client. Then open **Activities**, choose **Add activity**, enter a name, choose its **Kind**, and save.

Use **Project-specific** for work that belongs to one project. Choose that project when creating the activity; the activity is offered only for that project. Use **All projects** for reusable work that can apply across projects. When booking it, you may attribute that booking to a project or leave it under **No specific project**. Use **Internal** for internal work such as administration. It is grouped under the built-in **Internal** client, which is already present.

Create a client and project only when the work needs them. Internal and All-projects activities can be prepared without a new client or project. CapacityLens plans work at a week level; activities name the kind of work, rather than tracking individual tasks.

After the catalogue is ready, use [Book work](07-book-work.md) to place an activity on a person's row. If you cannot see **Add client**, **Add project** or **Add activity**, ask an Owner or Admin to confirm your Editor access.
