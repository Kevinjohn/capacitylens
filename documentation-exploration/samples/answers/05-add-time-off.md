# How should we record time off?

An **Editor**, **Admin** or **Owner** records a person's absence. Open **Time off**, choose **Add time off**, select the **Resource**, set **Start** and **End**, choose the **Type**, then select **Save**. Enter it before booking next week so the planner can review the conflict.

Time off covers whole days. It is not filtered by a person's working pattern, so a date range stays literal. A repeat creates separate dated entries; edit or remove each entry on its own.

## What happens to existing work?

Time off does not delete, shorten or move bookings. If work overlaps the absence, the Schedule marks the overlap red so the planner can decide whether to change it. Review the person's row and use **Edit allocation** or reassign the booking when a change is needed. See [Resolve overbooking](08-resolve-overbooking.md) for the adjustment path.

Viewers can see the time off but cannot record or change it. Ask the Editor, Admin or Owner who maintains the plan to add or correct an entry. Time-off notes are visible only to Owners and Admins, so keep private details out of notes if the whole team does not need them.

Company-wide closures are recorded separately by an Editor, Admin or Owner. A closure affects every person and placeholder in its date span, while personal time off applies to one resource. Neither kind of absence automatically reschedules work.
