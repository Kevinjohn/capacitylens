# Install with Docker

Docker deployment for the current AdonisJS application has not been validated. The checked-in
Dockerfile and Compose configuration still describe the retired server layout, so building or
starting them does not install the current application.

Use the [native release archive](/self-hosting/install-without-docker) for the current server. This
page will gain Docker instructions only after the image and its deployment path are rebuilt and
verified for the current application. No image behavior or Compose configuration is promised here.
