# Getting-started FAQ

These answers help when you are new to CapacityLens and are not sure which guide applies.

## Do I need to install anything to use CapacityLens?

Usually not. If your company already uses it, ask an Owner or Admin for an invitation and
start with [Day-to-day usage](/using/). Installation is a separate technical responsibility.

## Should I run the local demo first?

Only when you are evaluating or installing the software and are comfortable with a local
development setup. It is not the starting point for ordinary teammates.

## What is the fastest way to understand the product?

Read [What is CapacityLens?](/getting-started/what-is-capacitylens), then use [Make your
first booking](/getting-started/quick-start) in an existing company where you have editing access.

## I was made an Admin. Where do I start?

Use [Admin and settings](/admin/). It covers invitations, scheduled people, settings, work,
and the first booking without requiring you to follow the Owner or installation guides.

## I can only view the schedule. Is that expected?

Yes, if you have the Viewer role. Reading the schedule and finding capacity are useful
outcomes. Ask an Owner or Admin only if your responsibilities require editing access.
