# CapacityLens documentation

CapacityLens helps a small agency plan who is working on what, week by week, and see who
has room for more work. Choose the guide for your role.

| [Install and run CapacityLens](/self-hosting/) | Tech | Put CapacityLens on a server, hand it to the Owner, then back up, upgrade, monitor and recover it. |

Setup is shared between three people. The technical installer makes the service available, the
Owner creates the company and appoints an Admin, and the Admin prepares members and scheduling
data. One person can hold all three responsibilities, but you only need the guide for the job you
are doing now.

New to the product? Read [What is CapacityLens?](/getting-started/what-is-capacitylens), then
[make your first booking](/getting-started/quick-start).

## Not sure where to start?

<span id="get-more-help"></span>

**Do I need to install anything to use CapacityLens?** Usually not. If your company already uses
it, ask an Owner or Admin for an invitation and start with [Day-to-day usage](/using/).
Installation is a separate technical responsibility.

**Should I run the demo first?** Only when you are evaluating or installing the software. [Try
the demo](/getting-started/try-the-demo) is not the starting point for ordinary teammates.

**I was made an Admin. Where do I start?** Use [Admin and settings](/admin/). It covers
invitations, scheduled people, settings, work and the first booking without requiring you to
follow the Owner or installation guides.

**I can only view the schedule. Is that expected?** Yes, if you have the Viewer role. Reading the
schedule and finding capacity are useful outcomes. Ask an Owner or Admin only if your
responsibilities require editing access.
