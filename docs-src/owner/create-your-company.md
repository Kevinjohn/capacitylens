# Create your company

You sign in with the setup token from your installer, then create the company. You need the
CapacityLens address and that token.

## Sign in for the first time

![First Owner sign-in setup with Name, Email, Create a password and Owner setup token fields](../screenshots/flows/owner_first_signin_setup.jpg)

Open the address. The sign-in page says **Setup the account Owner**. Enter your name, email and
password, paste the token into **Owner setup token** and select **Create my sign-in**. The token is
not shown again. If you do not have it, or the form rejects it, ask the installer.

If the installer set up company login, choose that provider instead and use the email address the
installer approved for the first Owner. If no provider accepts your address, ask the installer to
check the first-Owner setup before you try a different identity.

## Create the company

![First company setup with Company name, Week starts on, Timezone, Language and Start with example data selected](../screenshots/flows/owner_first_company_setup.jpg)

Enter the **Company name**, then choose **Week starts on** and **Timezone**. The timezone list is
searchable and starts with your browser's timezone. These two apply to everyone and **cannot be
changed after creation**, so agree them with your team first. **Language** offers only English.

**Start with example data** is selected by default for your first company. It adds fictional people, a client, a project
and sample bookings. Clear it to start with an empty schedule. If adding the examples fails, the
company is still created; an Owner or Admin can retry from **Settings → Data and support → Example
data** while the company has no people, clients, projects or allocations. The in-memory demo does
not show this checkbox.

Select **Create company**. CapacityLens opens Schedule. Week start and timezone stay visible, read
only, under **Settings → Data and support → Company details**.
