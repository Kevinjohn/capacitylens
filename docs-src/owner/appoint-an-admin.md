# Appoint an Admin

Invite one person as Admin to run the company day to day. You stay the Owner.

![Team & access showing Invite someone with Admin, an email address and Create invite](../screenshots/flows/invite_admin_role_form.jpg)

1. Open **Team & access** and select **Invite someone**.
2. Set **Role** to **Admin** and enter their email.
3. Select **Create invite**. CapacityLens emails them the invitation; it lasts seven days.
4. When they have accepted, their address appears under **Waiting for approval**. Select
   **Approve**.

An invitation gives sign-in access; it does not put anyone on the schedule. If the email does not
arrive, select **Resend** under **Outstanding invites**.

## Hand over

![Team & access: accepted member showing Admin role](../screenshots/flows/owner_members_current.jpg)

When their row in **Team & access** shows **Admin**, send them
[Get the schedule ready](/admin/). If the invitation is still pending, ask whether they received the
email.
