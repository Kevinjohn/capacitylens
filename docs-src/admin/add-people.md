# Add people to the schedule

You give each person a row on Schedule so you can book their work and time off. They don't need a
sign-in. Editors, Admins and the Owner can add and edit people; Viewers cannot.

![Resources: Add resource and the person form with Working days](../screenshots/flows/admin_add_person_form.jpg)

Open **Resources** and select **Add resource**. Enter the **Name**, then add a **Role**, choose
**Engagement** and, if your company uses them, a **Discipline**. Create disciplines on the
[Disciplines page](/using/disciplines) first.

Set **Working days** to their usual week. Use **Start date** and **End date** if they are only
available for a set period. Select **Save**.

## Connect their sign-in

![Team & access: Link to Resource dialog for a member without a linked person](../screenshots/flows/admin_link_resource_choice.jpg)

If they also need to sign in, [invite them](/admin/invite-teammates). Then, in **Team & access**,
select the link icon beside the member and choose their row. The choice saves immediately.

Each person and each member can have only one link; remove an old link before reassigning it.
Linking does not change permissions or create a schedule row.

## Plan an unfilled role

When **Show placeholders** is on, select **Add placeholder** in Resources and choose its **Bound
project**. A placeholder stands for a role you have not filled yet. Its bookings stay tied to that
project and can use only that project's activities or the shared **All projects** ones. When
someone takes the role, edit or reassign the bookings to them.

Placeholders follow company working days. Turning the setting off hides them without deleting them.
If **Add placeholder** is missing, turn on **Show placeholders** in
[Company settings](/admin/company-settings).
