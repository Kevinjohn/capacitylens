# Code convention terminology

One word per concept, and one concept per word, in code, comments, tests, commit messages, documentation and
the UI. Decided in #2334.

The [glossary](docs-src/reference/glossary.md) is authoritative for the words users read. This page adds the
words developers read and keeps the two aligned. Where they differ on purpose, the table says so. The
[AdonisJS conventions](docs-src/reference/adonisjs-conventions.md#vocabulary) page defines the framework
terms this page reserves.

## Rules

1. **A framework word means only the framework thing.** AdonisJS, Lucid, VineJS, Japa, Bouncer, Ace,
   Account Kit, React, Zustand, Radix/shadcn, cmdk, TanStack Query, Playwright and Vitest own the words in
   [Framework reserved words](#framework-reserved-words). Product code does not reuse them for anything else.
2. **One concept, one word.** The entries below list the rejected synonyms. A rejected synonym is a defect
   when it is found, not a style preference.
3. **Code word and UI word match**, unless the entry records a deliberate pair (for example `masquerade` in
   code and "view as member" on screen).
4. **Package, header and package-config names keep their own spelling**:
   `@kevinjohn/adonisjs-origin-guard`, `Idempotency-Key`, `Content-Security-Policy`, `login_link_tokens` (an
   Account Kit table), `passwordPolicy` (an Account Kit config key), `requestKey` and `Operation` (the
   duplicate-request guard), `web_effective` (the Masquerade package's guard), `E_*` codes.
5. **Spelling.** Prose, UI copy and product-concept identifiers use British spelling (`utilisation`,
   `anonymise`, `colour` in copy, `catalogue`, `favourite`). Generic programming identifiers that mirror a
   platform or library keep American spelling (`color`, `normalize`, `serialize`, `initialize`,
   `authorization`). Write "AdonisJS", never "Adonis".
6. **Casing.** Product roles are capitalised in prose (Owner, Admin, Editor, Viewer) and lowercase as values
   (`'owner'`). "sign-in" is the noun, "sign in" the verb. "time off" is the noun, "time-off" the adjective.

## Enforcement

`pnpm run policy:terminology` reads the table below and fails on a rejected synonym in a file
name, in source, tests and scripts, in prose under `docs-src/`, `user-stories/` and root Markdown, and in
`apps/frontend/messages/`. `pnpm run check:changed` runs it on the changed files and the gate on the whole
tree. The check itself is the shared one from the
[code conventions](https://github.com/Kevinjohn/oss-adonisjs-code-conventions/blob/main/adonisjs/terminology.md),
installed as a development dependency; it also reads that repository's own table.
`terminology.config.json` holds the exemptions: vendored `components/ui`, generated
`.adonisjs/` output and the phrases that only contain a rejected word (`aria-modal`). A new
ruling changes this page and the code in one pull request. Names other software depends on (routes, environment
variables, wire values, error codes, table and column names, storage keys) keep their spelling until a
migration renames them.

### Review-only words

These words also have a legitimate second meaning, so the check cannot enforce them. A reviewer applies the
entries below.

- guard: type guard, authentication guard
- policy: Content-Security-Policy, passwordPolicy, CORS policy
- exception: a special case in prose
- organisation: the clients a company works for, and the autocomplete token
- assignee, assignment: copyright assignment, assignment expressions, GitHub CLI
- leave, absence: the verb and the ordinary noun
- recurring: a recurring workflow
- snapshot: Vitest snapshots, React getSnapshot, planning snapshots
- login, logout, register: Account Kit calls, HTTP Basic, library APIs
- view as, member view: the UI words "View as member" contain them
- administrator: a hosting administrator is the operator
- authority, capabilities: security prose and browser capabilities
- fake, double, support: fake timers, number types, ordinary support
- purge, transfer, rejection: cache purge, ownership transfer, promise rejection
- workspace: pnpm workspaces
